# Conhecimentos

Os módulos que o trainee estuda durante o treinamento, cada um com vídeo e explicação escrita. É o
que hoje está no Notion, em "Treinamento Introdutório" e "Módulo Introdutório", trazido para o
ODIN: versionado, revisado por PR e no mesmo lugar que a trilha.

O Claude do Projeto também pode ler esta pasta. Conecte o `manual-treinamento` ao conhecimento do
Projeto, junto com o repositório da equipe, e peça para ele explicar um módulo ou tirar dúvida
sobre ele.

## Por onde começar

| Pasta | O que tem |
|---|---|
| [00-primeiros-passos](00-primeiros-passos/) | Ambiente, programação, Git e GitHub: todo trainee faz |
| [engenharia-de-dados](engenharia-de-dados/) | Extração, SQL, ETL e cloud |
| [ciencia-de-dados](ciencia-de-dados/) | Limpeza, análise exploratória e machine learning |
| [inteligencia-de-negocios](inteligencia-de-negocios/) | Power BI, DAX e dashboards |
| [inteligencia-artificial](inteligencia-artificial/) | LLMs e provas de conceito |

Os portfólios são os mesmos do `CLAUDE.md` dos projetos. O validador diz quais módulos a equipe
precisa para o case; os de `00-primeiros-passos` valem para todos.

## Como é um módulo

Cada módulo é um arquivo `.md` dentro da pasta do portfólio, no [modelo de módulo](_modelo-de-modulo.md):
objetivo, pré-requisitos, vídeo, explicação passo a passo, exercício e próximos passos. O vídeo
fica fora do GitHub; o módulo guarda só o link.

O README de cada portfólio lista os módulos previstos e o status de cada um:

| Status | Quer dizer |
|---|---|
| a migrar | existe no Notion; falta trazer para cá e revisar |
| a criar | não existe ainda |
| sem vídeo | texto pronto, vídeo não gravado |
| pronto | texto e vídeo publicados |

Para escrever ou migrar um módulo: [como criar um módulo](como-criar-um-modulo.md).
